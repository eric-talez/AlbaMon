- Full unit run: 698 passed, 6 intentionally skipped local-provider tests; 61 files passed / 2 skipped. Full database run: 498 assertions across 10 files passed. Lint and production build/type analysis passed.
- Full browser regression: 25/25 passed. After the final visible-locality correction, the affected 3/3 launch tests were rerun on the final build. Exact commands and intermediate RED/fix results are in the task-11 report.
- One integration run navigated the employer browser before the separate admin approval POST committed. The test now waits for the employer caller’s stored approved status. This was a test synchronization issue, not a failed approval action.
- The full successful browser run reproduced two `The destination stream closed early` warnings (digest `3888609481`). No suppression or warning-only repeat was added; retain for D2.
- During native checks, the Playwright-owned server ended before one login navigation, producing Safari’s connection error. A dedicated owned server restored the check. A legacy seed identifier also returned the existing safe 404; the positive native detail check used a valid owned UUID fixture. Neither observation is labeled provider/device evidence.

The final native fixture and only its window were removed; the pre-existing Safari Start Page window was preserved. No browser/security settings were changed and WebDriver remains disabled.
- Actual `npm run build:release` exits 1 with `Missing release setting: NEXT_PUBLIC_SITE_URL`. Operator identity, domain, provider choices and reviewed policies remain unresolved. A configured local production build is not public launch approval.
